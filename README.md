# Bangkok Flood Lab — ทำไมกรุงเทพฯ น้ำท่วม?

แบบจำลอง 3 มิติบนเว็บ (Three.js) สำหรับนักเรียนและคนทั่วไป ใช้เรียนรู้ว่าน้ำท่วมกรุงเทพฯ เกิดจากอะไร
ผ่านกรอบ **"น้ำ 3 น้ำ"** ได้แก่ น้ำฝน น้ำเหนือ และน้ำทะเลหนุน รวมกับ **แผ่นดินทรุด**
และดูว่าระบบป้องกัน เช่น เขื่อนริมเจ้าพระยา คันกั้นน้ำ สถานีสูบน้ำ และอุโมงค์ระบายน้ำ ช่วยได้แค่ไหน

> ⚠️ แบบจำลองเพื่อการศึกษา ไม่ใช่การพยากรณ์ ตัวเลขทั้งหมดเป็นค่าประมาณ

## วิธีรัน

ต้องมี Node.js 20 ขึ้นไป

```bash
npm install
npm run dev        # เปิด http://localhost:5173
```

คำสั่งอื่น: `npm run build` (สร้างไฟล์สำหรับเผยแพร่ใน `dist/`), `npm run preview`, `npm test`, `npm run lint`

ต้นแบบดั้งเดิมแบบไฟล์เดียวเก็บไว้ที่ `prototype/index.html` (เปิดผ่าน static server ใดก็ได้)

## วิธีใช้งาน

1. **สถานการณ์ตัวอย่าง:** กดเลือก เช่น "วันปกติ", "ฝนตกหนักกลางเมือง", "น้ำเหนือหลาก", "น้ำทะเลหนุนสูง", "3 น้ำพร้อมกัน (แบบปี 2554)", "อนาคต: ทรุด + ทะเลสูงขึ้น"
2. **ปรับปัจจัย:** เลื่อนความแรงฝน ระยะเวลาฝน ปริมาณน้ำเหนือ ระดับน้ำทะเลหนุน และแผ่นดินทรุด
3. **เปิด/ปิดระบบป้องกัน:** ลองปิดเขื่อนหรือคันกั้นน้ำเพื่อดูว่าน้ำเข้าเมืองอย่างไร
4. **อ่านผล:** ระดับน้ำเจ้าพระยาที่ปากคลองตลาดเทียบกับสันเขื่อน พื้นที่น้ำท่วม แยกตามสาเหตุ และคำอธิบาย
5. **สำรวจ:** ลากเพื่อหมุนมุมมอง เลื่อนล้อเพื่อซูม ชี้เมาส์เพื่อดูความสูงพื้นและความลึกน้ำ
   ปุ่มด้านบนใช้สลับ "แผนที่ความสูง" และเลือกมุมกล้อง

## แหล่งข้อมูลและข้อจำกัด

- ภูมิประเทศ แนวแม่น้ำ คลอง เขื่อน และคันกั้นน้ำ **ประมาณจากแผนที่และข้อมูลสาธารณะ** ไม่ใช่ข้อมูลสำรวจหรือ DEM จริง
- ใช้วิธี "เติมน้ำตามความสูงพื้นที่" (bathtub / priority-flood) ที่ลดระดับตามระยะทาง ไม่ใช่การคำนวณการไหลของน้ำจริง
  ไม่มีมิติเวลาหรือปริมาตรน้ำ แอนิเมชันการไหลมีไว้ให้เห็นภาพเท่านั้น
- ความสูงพื้น (×0.6) และความสูงตึกถูกขยายเกินจริงเพื่อให้เห็นชัด
